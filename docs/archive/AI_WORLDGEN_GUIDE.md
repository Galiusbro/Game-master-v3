# AI-Enhanced World Generation Guide

## Обзор

Новая система AI-обогащения мира добавляет интеллектуальную генерацию описаний, имен и лора ко всем сущностям мира после создания структурного каркаса.

## Как это работает

### 1. Двухфазный подход

```
Фаза 1: Структурная генерация
├── География (континенты, моря, реки)
├── Регионы и биомы
├── Поселения и дороги
├── NPC и здания
└── POI и связи

Фаза 2: AI-обогащение (батчевое)
├── Генерация мирового лора
├── Обогащение континентов
├── Обогащение регионов
├── Обогащение поселений
├── Обогащение NPC
└── Обогащение POI
```

### 2. Иерархическая консистентность

AI-система передает контекст от родительских сущностей к дочерним:

- **Мир** → создает общий лор и тематику
- **Континенты** → используют мировой лор
- **Регионы** → используют континентальный контекст
- **Поселения** → используют региональный контекст
- **NPC** → используют контекст поселения

## Использование

### Вариант 1: AI-обогащение во время генерации

```python
from core.worldgen.pipeline import generate_world, WorldGenParams

# С AI-обогащением (по умолчанию)
params = WorldGenParams(
    seed="my_world",
    enable_ai_enrichment=True  # По умолчанию True
)

summary = await generate_world(params)
```

### Вариант 2: Двухфазный подход (рекомендуется)

```python
# 1. Быстрая генерация структуры мира
params = WorldGenParams(
    seed="my_world",
    enable_ai_enrichment=False
)
summary = await generate_world(params)
world_id = summary["world_id"]

# 2. AI-обогащение после генерации
from core.worldgen.ai_enrichment_service import ai_world_enrichment_service
enriched_summary = await ai_world_enrichment_service.enrich_world_batch(summary, world_id)
```

### Вариант 3: Через API (наиболее гибкий)

```bash
# 1. Генерация без AI (быстро)
curl -X POST http://localhost:8000/api/v1/world/generate \
  -H 'Content-Type: application/json' \
  -d '{"seed":"my_world","grid_size":128,"enable_ai_enrichment":false}'

# Получаем world_id из ответа, например: "2fbe4fae-f099-4af1-a161-5b2766393ca5"

# 2. AI-обогащение после генерации
curl -X POST http://localhost:8000/api/v1/world/enrich \
  -H 'Content-Type: application/json' \
  -d '{"world_id":"2fbe4fae-f099-4af1-a161-5b2766393ca5"}'
```

### Проверка результата

```python
ai_status = summary.get('ai_enrichment', {})
if ai_status.get('enriched'):
    print(f"✅ AI обогащение успешно: {ai_status['entities_processed']} сущностей")
else:
    print(f"❌ AI обогащение не выполнено: {ai_status.get('reason', 'unknown')}")
```

## Что обогащается

### 1. Мир (World)

- **Имя**: Запоминающееся название мира
- **Описание**: Богатое описание (2-3 параграфа)
- **Лор**: История, космология, мифы создания
- **Темы**: Центральные конфликты и мотивы
- **Хуки**: Зацепки для приключений

### 2. Континенты

- **Улучшенное имя**: Более выразительное название
- **Богатое описание**: Атмосферное описание (1-2 параграфа)
- **Культурная идентичность**: Доминирующие культуры и традиции
- **Примечательные особенности**: Уникальные ландшафты и опасности

### 3. Регионы

- **Улучшенное имя**: Более выразительное региональное название
- **Богатое описание**: Яркое описание сущности региона
- **Локальные характеристики**: Уникальные особенности и ресурсы
- **Региональные конфликты**: Местные напряжения и зацепки

### 4. Поселения (города, города, деревни)

- **Улучшенное имя**: Более выразительное название
- **Богатое описание**: Атмосферное описание поселения
- **Личность поселения**: Что делает это место уникальным
- **Местная политика**: Структуры власти и фракции
- **Хуки приключений**: Конкретные возможности для игроков

### 5. NPC

- **Улучшенное имя**: Более выразительное имя
- **Богатое описание**: Внешний вид и первое впечатление
- **Личность**: Основные черты, причуды, речевые паттерны
- **Предыстория**: Личная история и мотивации
- **Роль в сообществе**: Как они вписываются в поселение
- **Сюжетные зацепки**: Способы взаимодействия игроков

### 6. Точки интереса (POI)

- **Улучшенное имя**: Выразительное название с намеком на тайну
- **Богатое описание**: Атмосферное описание
- **История**: Предыстория и значимость
- **Текущее состояние**: Что там происходит сейчас
- **Хуки приключений**: Четкие причины для исследования

## Технические детали

### Архитектура

```python
class AIWorldEnrichmentService:
    def enrich_world_batch(summary, world_id):
        # 1. Построить мировой контекст
        context = build_world_context(summary)

        # 2. Обогатить в иерархическом порядке
        await enrich_world_entity(world_id, context)
        await enrich_continents(continents, context)
        await enrich_regions(regions, context)
        await enrich_settlements(settlements, context)
        await enrich_npcs(npcs, context)
        await enrich_pois(pois, context)
```

### Батчевая обработка

- Сущности обрабатываются параллельными батчами для эффективности
- Размеры батчей оптимизированы по типам сущностей
- Обработка ошибок позволяет продолжить при сбоях отдельных сущностей

### Промпт-шаблоны

Каждый тип сущности имеет специализированные промпт-шаблоны:

- **Системные промпты**: Определяют роль и требования
- **Пользовательские шаблоны**: Структурированные с контекстом и данными
- **D&D фокус**: Все промпты настроены на классическое D&D фэнтези

## Производительность

### Время генерации

- **Без AI**: ~10-30 секунд для мира среднего размера
- **С AI**: ~2-5 минут для мира среднего размера (зависит от API)

### Управление токенами

- Контекст обрезается для соблюдения лимитов токенов
- Иерархический контекст передается эффективно
- Батчевая обработка минимизирует API-вызовы

### Обработка ошибок

- Отказоустойчивость: мир остается функциональным при сбое AI
- Детальные логи ошибок для отладки
- Graceful degradation к базовым описаниям

## Настройка

### Параметры AI-сервиса

Настройте в `src/infrastructure/ai_service.py`:

- Модель (по умолчанию: зависит от конфигурации)
- Температура (по умолчанию: 0.7-0.9 в зависимости от типа)
- Максимальные токены (по умолчанию: 500-2000 в зависимости от типа)

### Кастомные промпты

Модифицируйте шаблоны в `AIWorldEnrichmentService._init_templates()`:

- Системные промпты для изменения стиля
- Пользовательские шаблоны для дополнительных данных
- Настройки температуры для творчества vs консистентности

## Лучшие практики

### 1. Размер мира

- Начинайте с малых миров для тестирования
- Большие миры требуют больше времени и токенов

### 2. Управление seed'ами

- Используйте описательные seed'ы для воспроизводимости
- Один seed генерирует одинаковый структурный каркас
- AI-обогащение может варьироваться при повторных запусках

### 3. Мониторинг производительности

- Следите за использованием токенов
- Настройте таймауты для API-вызовов
- Логируйте статистику обогащения

### 4. Итерационная разработка

- Тестируйте на малых мирах сначала
- Настраивайте промпты на основе результатов
- Балансируйте творчество и консистентность

## Устранение неполадок

### Общие проблемы

1. **AI-обогащение не работает**

   - Проверьте конфигурацию AI-сервиса
   - Убедитесь, что `enable_ai_enrichment=True`
   - Проверьте логи на ошибки API

2. **Медленная генерация**

   - Уменьшите размер мира (`grid_size`)
   - Проверьте размеры батчей в коде
   - Мониторьте лимиты скорости API

3. **Несогласованный лор**

   - Проверьте передачу контекста между уровнями
   - Настройте промпты для лучшей консистентности
   - Рассмотрите снижение температуры

4. **Ошибки памяти/токенов**
   - Проверьте лимиты токенов в шаблонах
   - Убедитесь, что контекст обрезается правильно
   - Мониторьте использование памяти
