Отлично, давай спроектируем “каноничную” проверку на дружбу в духе DnD.

### Что проверяем перед попыткой

- **Хард-блокеры**: NPC мёртв, в бою, недоступен (квест/сцена), явная враждебность — сразу отказ.
- **Контекст**: одна локация с игроком, видимость/дистанция ок, язык понятен, NPC не занят критически.
- **Кулдауны**: нет активного кулдауна на повторную попытку дружбы.

### Как считаем проверку (Persuasion)

- **Бросок**: d20 + модификатор Харизмы + профилирование в Persuasion + ситуативные модификаторы.
- **Базовый DC**: от базовой установки NPC к игроку.
  - friendly: 5, neutral: 10, unfriendly: 15, hostile: 20.
- **Модификаторы DC**:
  - +1..+5: важность NPC, плохое настроение, неподходящее место/время, репутация игрока низкая.
  - −1..−5: уместный подарок/помощь, общая фракция, удачная предварительная реплика.
  - Advantage/Disadvantage: по сильным факторам (общий язык/культурный контекст, недавняя помощь/оскорбление).
- **Источник факторов**:
  - `npc.current_state.current_mood`, `importance_level`.
  - Классификатор настроений/установки: `command_classifier.classify_npc_attitude(npc.description/поведение)` для seed.
  - Недавние события: через `event_store.get_entity_history(...)` (вес последних N записей).
  - Контекст локации: `context_builder`.

### Результат проверки

- **Успех**:
  - Поднять “расположение” к игроку (см. ниже) и, если порог перейдён, установить `relationship_to_player[player_id] = "friendly"`.
  - Снять/уменьшить кулдауны.
- **Провал**:
  - Снизить “расположение”, добавить мягкий кулдаун, при критическом провале — временная “suspicious”.
- **Крит. успех/провал**: сильнее изменяем “расположение”, особые реплики.

### Минимальные изменения модели

- В `NPCState`:
  - Добавить `disposition_to_player: Dict[UUID, int] = {}` (диапазон условно −100..100).
  - Добавить `social_cooldowns: Dict[UUID, str] = {}` с ISO-временем (или `datetime`, но сериализуем в строку).

### Где реализовать

- В `src/api/handlers/dialogue_handler.py`:
  - Перед установкой дружбы: вызвать “социальную проверку”.
  - Собрать модификаторы: `player` статы (Харизма, проф. Persuasion), настроение/важность NPC, контекст локации, события.

  - `world_service.apply_disposition_change(npc, player, delta:int)`.

### Бизнес-правила по умолчанию

- **Порог дружбы**: disposition ≥ 50 → friendly; <−50 → hostile; иначе neutral.
- **Дельты**: успех +10 (кр.успех +20), провал −10 (кр.провал −20).
- **Кулдаун**: 10 минут за провал, 1 минута за обычный успех (чтобы не спамили).
- **Кепы**: −100..100.
- **Разовые бонусы**: подарок/квест-помощь дают временный −5 к DC на один бросок.
