def handle_action(intent, slots, session):
npc = resolve_npc(slots, session) # Qdrant + фильтры
action = actions_registry.match(intent, target="npc")

    assert preconditions_ok(action, session.state, npc)

    atk = compute_attacker_stat(session.player, action)
    dfn = compute_defender_stat(npc, action, session.env)

    roll_seed = make_seed(session.id)
    atk_roll = d20(roll_seed, advantage=adv_from_env(session, action)) + atk.mod
    dfn_roll = passive_or_active(npc, action, roll_seed) + dfn.mod

    outcome = decide_contest(atk_roll, dfn_roll)  # crit/success/mixed/fail/crit-fail
    effects = apply_outcome(outcome, action, session, npc, slots.item)

    log_event({
        "seed": roll_seed, "atk_roll": atk_roll, "dfn_roll": dfn_roll,
        "mods": {"env": session.env, "atk": atk, "dfn": dfn}, "outcome": outcome, "effects": effects
    })

    return narrate(outcome, effects, session, npc)  # LLM текстово отыгрывает

   «Спрошу у кузнеца, есть ли работа»
   «Хочу поболтать с магом»
   Слоты: target_npc, topic
2. Ask
   Описание: Задать NPC вопрос (часто внутри диалога).
   Примеры:
   «Спроси у него, где трактир»
   «Узнай, что слышно про бандитов»
   «Попроси рассказать про этот артефакт»
   Слоты: target_npc, topic
3. Buy
   Описание: Купить предмет или услугу.
   Примеры:
   «Купить у торговца меч»
   «Закажи кружку эля»
   «Сниму комнату на ночь»
   Слоты: target_npc, item, quantity
4. Sell
   Описание: Продать предмет.
   Примеры:
   «Продать шкуру волка»
   «Сдать ему камень за золото»
   Слоты: target_npc, item, quantity
5. Steal
   Описание: Попробовать украсть предмет.
   Примеры:
   «Обокрасть трактирщика»
   «Стащить кошелёк у прохожего»
   Слоты: target_npc, item
6. Attack
   Описание: Атаковать цель.
   Примеры:
   «Ударить орка»
   «Выстрелить в гоблина»
   Слоты: target, weapon
7. CastSpell
   Описание: Применить заклинание.
   Примеры:
   «Кинуть огненный шар в тролля»
   «Применить лечащую магию на себе»
   Слоты: spell, target
8. Move
   Описание: Перейти в другую локацию/зону.
   Примеры:
   «Пойти в таверну»
   «Выйти на улицу»
   «Перейти на рынок»
   Слоты: location
9. Inspect
   Описание: Осмотреть объект/место/персонажа.
   Примеры:
   «Осмотреть сундук»
   «Внимательно глянуть на бармена»
   «Изучить амулет»
   Слоты: target, detail
10. UseItem
    Описание: Использовать предмет из инвентаря.
    Примеры:
    «Выпить зелье здоровья»
    «Использовать ключ от сундука»
    Слоты: item, target
11. PickUp
    Описание: Подобрать предмет.
    Примеры:
    «Поднять монету»
    «Взять меч с пола»
    Слоты: item
12. Give
    Описание: Передать предмет NPC или игроку.
    Примеры:
    «Отдать кольцо магу»
    «Передать зелье другу»
    Слоты: item, target
13. SkillCheck
    Описание: Инициировать проверку навыка (акробатика, скрытность, убеждение…).
    Примеры:
    «Попробовать пролезть в окно»
    «Переубедить стражника»
    Слоты: skill, target, context
14. Rest
    Описание: Отдых, сон, восстановление.
    Примеры:
    «Переночевать в таверне»
    «Сесть отдохнуть у костра»
    Слоты: location, duration
15. Inventory
    Описание: Проверить или управлять инвентарём.
    Примеры:
    «Посмотреть, что у меня есть»
    «Проверить золото»
    Слоты: нет или item
